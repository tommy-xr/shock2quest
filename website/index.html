Install

Sideload in three steps

Quest in Developer Mode · adb · System Shock 2: 25th Anniversary Remaster (GOG / Steam)

  1. Download the APKLatest release ↗
  2. Install it over USB
    adb install -r shock2quest-<version>.apk
  3. Copy your game files
    adb shell mkdir -p /sdcard/shock2quest/mods adb push *.kpf /sdcard/shock2quest/ adb push mods/*.kpf /sdcard/shock2quest/mods/ adb push cutscenes /sdcard/shock2quest/

Launch from Unknown Sources. Windows commands and updating: INSTALL.md
